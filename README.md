# Understudy

Know who can step in before you need them. Understudy measures how many people a team can lose before nobody can help with a system, using max-flow on a FalkorDB graph of Kubernetes.

Built for Graph Hacks: Context for AI Agents (WeMakeDevs x FalkorDB), Oct 15 to 18, 2026.

Work in progress. Setup steps, the graph model and the queries will be written up here as they land.
